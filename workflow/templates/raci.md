# RACI — regulatory inquiry response

One RACI per inquiry, filled at triage. Attach to the inquiry record.

**Rule that makes this work:** every row names an individual, never a team. "Legal" is not
an owner. A team cannot miss a deadline, which is precisely why assigning work to one is
comfortable and useless.

| Activity | Responsible | Accountable | Consulted | Informed |
|---|---|---|---|---|
| Confirm legal basis and deadline against instrument text | Program manager | Regional counsel | — | Regional lead |
| Decide whether to seek an extension | Program manager | Regional lead | Counsel, Gov Affairs | Exec sponsor |
| Decompose inquiry into per-SME questions | Program manager | Program manager | SME leads | — |
| Answer each assigned question | Named SME | SME's manager | — | Program manager |
| Prior-filing consistency scan | Program manager | Regional counsel | Policy leads in affected jurisdictions | Regional lead |
| Consolidate into a single narrative | Program manager | Program manager | — | SMEs |
| Legal review (accuracy, privilege, commitments) | Regional counsel | Regional counsel | Policy | Program manager |
| Policy review (positional consistency) | Regional policy lead | Regional policy lead | Other-jurisdiction policy | Program manager |
| Pre-submission QA | Program manager | Program manager | — | Approver |
| Approve for filing | — | Named approver per matrix below | Counsel | Exec sponsor |
| File and capture receipt | Program manager | Program manager | — | All above |
| Log commitments made and secure funding | Program manager | Regional lead | Finance/eng owner | Exec sponsor |

## Approval authority

| Priority | Approver | Notes |
|---|---|---|
| P1 | Regional lead + General Counsel delegate | Exec sponsor named within 1 hour of intake |
| P2 | Regional lead | Counsel sign-off required before filing |
| P3 | Program manager | Counsel sign-off where any commitment is made |
| P4 | Program manager | Batch-approved at weekly intake |

## The two rows people skip

**Prior-filing consistency scan.** Skipped because it feels like overhead when the deadline
is tight. It is the row that prevents an answer given in Canberra from contradicting one
given in Tokyo eighteen months later, at a point when neither author is still in the role.

**Log commitments and secure funding.** A commitment made to a regulator that nobody funds
does not fail loudly. It fails at the next inquiry, when the regulator asks what happened
to it — and the honest answer is worse than the original gap would have been.
